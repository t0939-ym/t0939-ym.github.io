# 提示詞

把灰底區塊整段複製，貼給你的 AI。方括號 `［ ］` 裡的內容換成你自己的。

不論用哪一個提示詞，都不要把真實的學生名單、照片或密碼貼給 AI。

## 提示詞 1：請 AI 幫我發布（AI 可以讀寫電腦上的檔案）

適用 Claude Code、Codex、Cursor、Gemini CLI 這類工具。先用它打開這個資料夾。

```
請先讀這個資料夾裡的 AGENTS.md，然後帶我把這個座位表工具發布到我自己的 GitHub Pages，並接上我自己的 Google 試算表。

我不會寫程式。你能自己做的步驟請直接做；需要我在瀏覽器裡操作的步驟，請一次只給我一步，等我回報結果再給下一步。

全部完成後，請帶我用「示範資料」資料夾裡的假名單測試一次，確認學生端和教師端都能用，最後告訴我學生填寫頁和教師端的網址。
```

## 提示詞 2：請 AI 一步一步教我發布（聊天視窗）

適用 ChatGPT、Gemini、Claude 網頁版。先把 `README.md` 和 `AGENTS.md` 兩個檔案上傳或貼給它。

```
我是中學老師，不會寫程式。我拿到一套座位表工具，要放到我自己的 GitHub Pages，並接上我自己的 Google 試算表。上面兩份文件是這套工具的說明。

請依照文件帶我完成。規則：
1. 一次只給我一個步驟，告訴我要點哪裡、會看到什麼畫面。等我說「好了」或貼上我看到的畫面文字，再給下一步。
2. 我卡住時會把畫面上的文字貼給你，請用白話解釋原因和怎麼處理。
3. 不要請我把密碼貼給你。

我目前的狀況：［例如：已經有 GitHub 帳號／還沒有 GitHub 帳號］。請從第一步開始。
```

## 提示詞 3：只接後端（網頁已經發布）

```
我的座位表網頁已經發布在 ［你的 GitHub Pages 網址］，但教師端顯示「尚未接上後端」。

請依照 AGENTS.md 的「建立後端」和「接上後端」，帶我建立 Google 試算表與 Apps Script，並把網址填進 config.js。一次只給我一步。
```

## 提示詞 4：回報錯誤

看到紅字或錯誤訊息時，不用看懂，整段貼回去。

```
座位表工具出錯了。

我在做的事：［例如：學生按「送出」／教師端登入／匯入照片名冊］
用的裝置和瀏覽器：［例如：iPhone 的 Safari］
畫面上的完整訊息：
［貼上整段文字］

教師端「架設說明 → 測試連線」的結果：
［貼上結果，沒有做就寫「還沒做」］

請用白話解釋原因，告訴我要怎麼處理。如果需要改程式，先告訴我會改哪些檔案，以及改完要不要在 Apps Script 部署新版本。
```

## 提示詞 5：加一個功能

一次只加一個功能，壞了才知道是哪一步出問題。

```
請在不改動既有功能的前提下，替座位表工具加一個功能：

［用一兩句話描述。例如：教師端可以把座位表匯出成 CSV 檔。］

要求：
1. 動手之前先告訴我你打算怎麼做、會改哪些檔案，等我同意再改。
2. 遵守 AGENTS.md 的規定：學生資料和密碼不能寫進檔案，不能把資料送到 Google 試算表以外的地方。
3. 改完執行測試。
4. 最後告訴我：改了哪些檔案、我需不需要在 Apps Script 貼上新程式並部署新版本。
```

## 提示詞 6：檢查這份程式會碰哪些資料

把別人給的程式用在學生身上之前，先請 AI 幫你看一遍。

```
請閱讀這個資料夾裡的 apps-script.gs 和所有 .js、.html 檔案，用白話回答：

1. 後端程式會讀取、修改我 Google 帳號裡的哪些資料？
2. 有沒有任何資料會被送到 Google 試算表以外的地方，例如寄信、連到其他網站？
3. 學生的姓名、座位、照片各自存在哪裡？誰看得到？
4. 部署成「所有人」可以存取，實際上代表什麼？靠什麼保護？
5. 有沒有你覺得我應該知道的風險？

請列出你是根據哪個檔案的哪一段得出答案。
```

## 提示詞 7：換成我們班的設定

```
請帶我把座位表工具設定成我們班的樣子。這些都在教師端的「設定」分頁就能改，不需要改程式，請告訴我每一項要怎麼填：

教室座位：［例如：6 排，每排 6 個；最左和最右兩排只有 5 個，第一個位子比隔壁排後面一格］
講桌位置：［例如：第 4 排的前面］
幹部：［列出職位］
小老師科目：［列出科目］
```
